◆ check_satisfiability()

bool check_satisfiability ( std::string filepath)

This function is used to check the satisfiability of a CNF file The satisfiability of a CNF expression is the ability to select a specific combination of truth values of the given variables such that the given expression evaluates to True This problem is considered NP-Complete, ie, all 2^n possibilities must be explored to determine the answer in the worst case. given that m is the number of variables and n is the number of clauses.

Time Complexity : O(m * n * 2^m) Space Complexity: O(m * n)

Output: boolean : True if the cnf expression is valid/satisfiable.
