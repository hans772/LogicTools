# Logical Expression Parser and SAT Solver

This C++ project provides a robust toolkit for parsing, manipulating, and evaluating propositional logic expressions. It constructs a binary parse tree from an infix or prefix expression, allowing for various transformations and analyses, including conversion to Conjunctive Normal Form (CNF) and checking for satisfiability.

## Features

-   **Expression Parsing**: Parses fully parenthesized logical expressions in infix notation and space-separated expressions in prefix (Polish) notation.
-   **Binary Parse Tree**: Constructs an in-memory binary parse tree representation of the logical expression.
-   **Notation Conversion**:
    -   Converts an infix expression to its prefix equivalent.
    -   Reconstructs an infix expression from the parse tree.
-   **Tree Analysis**:
    -   Calculates the height of the parse tree.
    -   Evaluates the truth value of the expression given user-defined values for atomic variables.
-   **Logical Transformations**:
    -   **Implication-Free (IMPL\_FREE)**: Eliminates implication operators (`>`) by rewriting `A > B` as `~A + B`.
    -   **Negation Normal Form (NNF)**: Moves negation operators (`~`) inwards so they only apply to atomic variables.
    -   **Conjunctive Normal Form (CNF)**: Converts the expression into a conjunction of disjunctions. *Note: This can lead to an exponential increase in the size of the expression.*
-   **DIMACS CNF Output**: Generates a standard `.cnf` file in DIMACS format from the CNF representation of the input expression.
-   **SAT Solver**: Includes a basic brute-force SAT solver to check the satisfiability of the generated CNF file.
-   **Tree Visualization**: Prints a formatted, human-readable representation of the parse tree to the console (requires a Windows environment).

## Operators and Notation

The parser recognizes the following operators with the precedence `+` < `*` < `>`:

| Operator | Symbol | Meaning       |
| :------: | :----: | :------------ |
| Negation |  `~`   | NOT           |
| Disjunction |  `+`   | OR            |
| Conjunction |  `*`   | AND           |
| Implication |  `>`   | IMPLIES       |

**Input Format**:
-   **Infix**: Expressions must be **fully parenthesized**.
    -   Example: `((A * B) > ~C)`
-   **Prefix**: Operators and operands must be separated by spaces.
    -   Example: `> * A B ~ C`

## File Structure

-   `main.cpp`: The main driver file that orchestrates the program flow. It takes user input, builds the tree, and performs all the required operations.
-   `parse_tree.hpp`: The header file containing the declarations for the `ParseTree`, `TreeNode`, and `Atom` classes, along with helper function prototypes.
-   `parse_tree.cpp`: The implementation file containing the logic for parsing, tree manipulation, transformations, and the SAT solver.
-   `cnf_output.cnf`: The output file generated by the program, containing the CNF representation of the user's input expression in DIMACS format.

## How to Compile and Run

### Prerequisites

-   A C++ compiler that supports C++11 or later (e.g., g++, Clang, MSVC).
-   **Windows Environment**: The tree printing functionality (`print_tree()`) uses Windows-specific headers (`windows.h`, `io.h`). The program will compile on other systems (like Linux or macOS) if this functionality is commented out, but it is required for the default `main.cpp`.

### Compilation

Open a terminal or command prompt and run the following command to compile the source files:

```sh
g++ main.cpp parse_tree.cpp -o logic_parser.exe
`
